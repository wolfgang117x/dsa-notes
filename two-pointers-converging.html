Two Pointers: Converging Pattern

Core Concept: Use two indices starting at opposite ends of a sequence, moving toward each other based on a condition derived from sorted order or monotonic properties. This reduces O(N²) brute force searches to O(N) linear scans.

1. Why It Works

The pattern relies entirely on Monotonicity. If an array is sorted (or has a predictable gradient like area in Container With Most Water), moving a pointer in one direction guarantees a predictable change in the computed value.

  • If value < target: We need a larger value → Move Left Pointer Right (increase).
  • If value > target: We need a smaller value → Move Right Pointer Left (decrease).
  • Termination: Pointers meet (left >= right).

3. Criteria: When to Use (and When Not To)

✅ Apply When:

  • Input is sorted or can be sorted without losing necessary index info.
  • You are looking for pairs/triplets satisfying a condition (sum, product, area).
  • You need to compare elements from both ends moving inward (palindrome, merge, partition).
  • Brute force is O(N²) but the relationship between adjacent elements is monotonic.

❌ Do NOT Use When:

  • Data is unsorted AND sorting destroys required information (e.g., original indices matter and you can't store them).
  • No monotonic property exists (random data where moving L/R gives no directional hint).
  • You need all possible combinations regardless of order (use backtracking/bitmask).
  • Hash Map O(N) solution exists for unsorted data (e.g., standard Two Sum I).

4. Tradeoffs

  • Pros: Optimal time complexity, usually O(1) extra space (in-place), simple implementation.
  • Cons: Requires sorted input (O(N log N) preprocessing cost), tricky boundary conditions (off-by-one errors), duplicate handling logic adds verbosity.
  • Vs Hash Map: Two pointers wins on space (O(1) vs O(N)) and often constant factors. Hash map wins if data cannot be sorted.

// Template for finding pair with condition in sorted array
int left = 0, right = arr.length - 1;
while (left < right) {
    int current = compute(arr[left], arr[right]);
    
    if (current == target) {
        // Found exact match
        return new int[]{left, right};
    } else if (current < target) {
        left++;   // Need larger value
    } else {
        right--;  // Need smaller value
    }
}
return -1; // Not found

B. K-Sum Generic (3Sum / 4Sum / Closest)

// 3Sum Template - Extendable to K-Sum via recursion
List> threeSum(int[] nums) {
    Arrays.sort(nums); // CRITICAL
    List> res = new ArrayList<>();
    
    for (int i = 0; i < nums.length - 2; i++) {
        // Skip duplicate anchors
        if (i > 0 && nums[i] == nums[i-1]) continue;
        
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // Skip duplicates for L and R
                while (left < right && nums[left] == nums[++left]);
                while (left < right && nums[right] == nums[--right]);
            } else if (sum < 0) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}

while (l <= r) { // Note: <= because single person still needs boat

    }

D. Dual Array Merge (Intersection / Squares)

// Intersection of Two Sorted Arrays
int i = 0, j = 0;
Set intersection = new HashSet<>();
while (i < a.length && j < b.length) {
    if (a[i] == b[j]) {
        intersection.add(a[i]);
        i++; j++;
    } else if (a[i] < b[j]) {
        i++;
    } else {
        j++;
    }
}
